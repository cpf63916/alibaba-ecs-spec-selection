## 规格族命名怎么读：首字母就是用途提示

阿里云实例规格族的名字本身就在告诉你它擅长什么。记住几个高频前缀，大部分场景能自己选对，不用死记型号。

- **g 开头（通用型）**：CPU 与内存配比 1:4，官方选型文档里企业后台应用、手游页游、视频转发的默认推荐。
- **c 开头（计算型）**：CPU 吃重、内存要求一般，Nginx 这类高频建连的应用归它，视频转码场景官方直接点名 c8y。
- **r 开头（内存型）**：配比拉到 1:8，Redis、Memcache 这类缓存和高性能数据库的菜。
- **i 开头（本地SSD型）**：搭配 NVMe 本地盘，主打高 IOPS 和低读写时延。官方文档的原话是重载数据库推荐 i 系列；轻载数据库用 i4r、i4g 配云盘，性价比更高。
- **d 开头（大数据型）**：高存储吞吐，Hadoop、HDFS 离线计算优先选这个系列，Elasticsearch 大集群同样归它。
- **hfc 开头（高主频）**：高性能端游和高性能计算场景，配比 1:2。
- **GPU 实例**：AI 训练和推理用。官方给的配比参考是深度学习训练 GPU:CPU 约 1:8 到 1:12，图像识别推理 1:4 到 1:12，语音识别推理 1:16 到 1:48。
